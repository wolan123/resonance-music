# LUMEN 流光音乐 · Shared Music Site

一个类 QQ 音乐模式的共享云音乐网站：融合网易云 / QQ 音乐全曲库，首页发现、歌单、排行榜、我的，沉浸光效，歌词自动联网匹配。

线上地址：https://resonance-music-wolan123s-projects.vercel.app

备用地址：https://lumen-radio.vercel.app

## 功能

- **账号体系**：用户名 + 密码注册/登录（scrypt 加盐哈希 + AES-256-GCM 加密存储）
- **发现页**：轮播 Banner、推荐歌单、全网热歌榜、云音乐新歌、本站热播
- **歌单系统**：创建/删除歌单、搜索云音乐加歌、歌单详情（封面拼图、播放全部）
- **排行榜**：网易云 + QQ 音乐全网榜单实时融合（热歌榜 / 新歌榜 / 本站热播）
- **我的**：最近播放、我的收藏、我的歌单
- **播放队列**：底部播放条可打开队列抽屉，移除/清空队列
- **全屏播放页（QQ 音乐式）**：点歌即单开一页——旋转唱片封面 + 同步歌词 + 大控制区（进度/上一首/播放/下一首/音量/加入歌单/特效切换）
- **播放特效（QQ 音乐动感风格）**：动感（炫彩频谱 + 旋转光轮）、极光、脉冲三种模式，低音节拍检测驱动光环扩散，可一键开关
- **歌词**：随播放同步滚动高亮，点击歌词跳转；播放时自动联网匹配歌词（lrclib，服务端匹配并保存，大家都能用）
- **云音乐（网易云 / QQ 音乐）**：绑定你的网易云或 QQ 音乐账号（扫码登录），即可搜索并直接播放两大平台的曲库；会员歌曲用你的会员身份播放，歌词自动走平台接口匹配。播放链接按需获取、不落盘
- **共享会员（管理员）**：管理员（`ADMIN_USERNAMES` 环境变量指定）可在云音乐页绑定共享会员，绑定后全站用户无需登录即可用该会员播放；凭证 AES 加密存服务器、不对外展示，普通用户只能使用、不能查看/修改
- **播放计数**：本站热播按全站真实播放次数排行（云歌曲也会计入）
- **响应式**：桌面 / 移动端都可用

## 云音乐说明

- 入口在侧边栏「云音乐」，可切换网易云 / QQ 音乐两个平台
- 未登录时可以先搜歌、看歌词、看榜单；免费歌曲可直接播放，会员歌曲需要登录态
- 登录凭证只保存在你自己的浏览器 localStorage，不会上传到服务器
- 管理员绑定共享会员后，凭证加密保存在服务器（Vercel Blob），所有用户播放时自动使用；普通用户无任何查看/解绑入口
- 网易云：扫码登录后可播放会员/高音质歌曲；QQ 音乐：扫码登录后使用你的 QQ 音乐会员身份获取播放链接
- 各平台的播放链接由服务端实时获取（有有效期），不下载、不缓存歌曲文件
- 管理员配置：在 Vercel 项目设置里添加环境变量 `ADMIN_USERNAMES`（多个用英文逗号分隔），值为你在本站注册的账号名

## 技术架构

- 前端：React 19 + Vite + Tailwind CSS v4 + Framer Motion
- 存储：Vercel Blob（歌单、榜单缓存、云播放统计各一个 JSON 文件，天然避免并发覆盖）
- API：Vercel Serverless Functions（`api/rankings.js` 实时融合双平台榜单，`api/playlists.js` 管理歌单，`api/play.js` 记录云歌曲播放）
- 元数据解析：`music-metadata`（浏览器端读取 ID3/FLAC/MP4 标签与内嵌封面）

## 本地运行

```bash
npm install
npm run dev
```

注意：本地开发时 API 需要 Vercel 环境（`vercel dev` 或直接部署后访问线上）。
